# 10. 원천 대비 수집 완전성

점검일: 2026-09-22. 동국대 공식 사이트를 직접 조회(목록·API 읽기만)해 DB와 대조했다. 수집기 실행, DB 쓰기, 재색인은 하지 않았다.

## 요약

| 데이터 | 사이트 | DB | 판정 |
|---|---|---|---|
| 공지 9개 게시판 | 2023년 이후 5,759건 | 활성 5,630건 | 2023-01~2026-08-28 누락 **0건**. 08-29 이후 **153건 전부 누락**. 사이트에서 삭제됐는데 DB 활성 **24건** |
| 공지 본문 | — | 본문 빈 글 1,445건 | 샘플 12/12가 포스터 이미지만 있는 글. OCR은 2026-08부터만 적용 |
| 공지 첨부 | — | 첨부 5,642개(PDF 2,425·HWP 2,305) | 파일명·링크만 저장, 내용 미수집 |
| 학칙 | 공식 현행 514건 | 520행(HWP 스냅샷 511 + 공식 웹 8) | 최신 346, **구판 117**, 이름 변경 22, **누락 29**, 공식에 없는(폐지 추정) 24 |

| 도서관 운영시간 | — | 08-02~08-30 | 공지 작업에 딸려 있어 08-30에서 멈춤 |

## 원인

1. **정기 수집 전체가 2026-08-29 18:02 이후 멈췄다.** 운영자가 서버를 내린 것이 원인이다(결함 아님). 다만 멈춤을 알려 주는 장치가 없어 23일간 드러나지 않았다. 재기동하면 공지 153건은 다음 정기 수집(게시판당 앞 3페이지)에 대부분 따라오지만, 게시판별로 30건을 넘게 밀린 일반·학사·장학공지는 3페이지로 부족할 수 있으므로 첫 실행은 페이지 수를 늘려야 한다.
2. **학칙 수집 범위가 제2편 제1장(SEQ=6)뿐이다.** 공식 사이트는 81개 분류·514건인데 정기 수집은 학부 학칙 5건만 갱신한다. 나머지는 과거 HWP 스냅샷이라, 수집기가 정상 동작해도 구판 117건과 누락 29건은 해소되지 않는다. 누락에는 일반·영상·특수·경영전문·의학전문대학원 학칙시행세칙, 대학원 장학금 지급내규처럼 학생 문의가 잦은 규정이 포함된다.
3. **교직원은 정기 수집 대상이 아니다.** 스케줄러에 작업이 없다.
4. **공지 증분 수집은 삭제를 감지하지 못한다.** 앞 3페이지만 새 글 위주로 보므로, 사이트에서 지운 글(상세 URL이 302 리다이렉트)이 DB에 활성으로 남는다. 재게시로 제목이 같은 글의 옛 판도 남는다.
5. **학식 사이트는 식단 게시 전 날짜도 "휴무"로 표시한다.** 수집 시점에는 미게시와 실제 휴무를 구분할 수 없다. 매일 재수집으로 따라잡는 구조인데 1번 때문에 멈췄다. 미래 날짜의 "휴무"는 답변에서 단정하면 안 된다.
6. **본문 정보가 이미지와 첨부에 있다.** OCR(`RAG_NOTICE_IMAGE_OCR_ENABLED`, 기본 켜짐)은 수집 시점에만 적용되어 2026-08 이전 글에 소급되지 않았다. 첨부 파일 내용 추출 경로는 없다.

## 부수 관찰

- OCR 이미지 크기 상한(`RAG_NOTICE_IMAGE_OCR_MAX_BYTES`, 5MB) 때문에 고해상도 포스터(예: 6.7MB 주거안정장학금 안내)는 OCR 대상에서 조용히 빠진다.

- 공지 게시판은 마지막 페이지를 넘겨 요청하면 빈 목록이 아니라 상단 고정글을 반복해서 돌려준다. `collect_board`의 `if not notice_list: break`는 사실상 동작하지 않고, 전체 수집의 종료는 "2023년 이전 글 5건 연속" 조건에만 의존한다. 정기 수집은 `max_pages=3`이라 영향이 없다.
- 교직원 이름은 원천 API에서 이미 `김**`처럼 가려져 있고 이메일도 비어 있다. 이름 기반 조회 불가는 수집 문제가 아니라 원천의 한계다.

## 권장 순서

- P0: 서버 재기동 시 공지 첫 수집은 페이지 수를 늘려 밀린 글을 채운다. 데이터셋별 "마지막 성공 수집 시각"에 경보를 건다.
- P0: 학칙 수집을 공식 사이트 81개 분류 전체로 넓히고 HWP 스냅샷을 공식판으로 대체한다. 공식에 없는 24건은 폐지 여부를 확인해 숨긴다.
- P1: 교직원 주기 수집(주 1회) 추가. 공지 삭제 감지(최근 N개월 목록 전수 대조 또는 상세 302 확인).
- P1: 2026-08 이전 이미지 전용 공지 1,445건 OCR 소급(외부 API 비용 발생). 첨부 PDF·HWP 본문 추출 검토.
- P2: 2024·2025 교과과정 수집, PDF·학과 페이지 중복 교과목 병합.
